## 4. 事件传递流程图

```
用户输入事件
    │
    ↓
┌───────────────────────┐
│  LÖVE2D Input Event   │
│  (mouse/touch/key)    │
└───────────┬───────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│ 平台适配层                                 │
│ • Windows: mousepressed                   │
│ • Android: touchpressed                   │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  GUI Manager                              │
│  gui:mousepressed(id, x, y)               │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  1. 检查 input_state                      │
│     • hover_view (焦点视图)               │
│     • pressed_views[] (按下的视图)        │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  2. 碰撞检测                              │
│     view:containsPoint(x, y)              │
│                                           │
│     从顶层(Layer 1)开始扫描               │
│     └─> 按 _draw_order 倒序遍历           │
└───────────┬───────────────────────────────┘
            │
            ├─ No Hit ──> 无操作
            │
            ↓ Hit!
┌───────────────────────────────────────────┐
│  3. 事件拦截检查                          │
│     view:_event_intercept(x, y)           │
│                                           │
│     • true: 继续扫描子视图                │
│     • false: 拦截，不向下传递             │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  4. 递归扫描子视图                        │
│     for child in children (倒序)          │
│         if child:containsPoint(x, y) then │
│             return child                  │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  5. 找到目标视图                          │
│     • 更新 input_state                    │
│     • 更新 hover_view                     │
│     • 更新 keypressed_view                │
└───────────┬───────────────────────────────┘
            │
            ↓
┌───────────────────────────────────────────┐
│  6. 调用视图事件处理                      │
│     view:_mousepressed(id, x, y)          │
│     view:_mousemoved(id, x, y)            │
│     view:_mousereleased(id, x, y)         │
│     view:_on_click(id, x, y)              │
└───────────────────────────────────────────┘
```

## 6. 布局计算流程 (Line Layout 示例)

```
┌─────────────────────────────────────────┐
│  line_layout                            │
│  orientation: "vertical"                │
│  padding: 10                            │
│  width: 300, height: 400                │
└────────────┬────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────┐
│  1. 计算可用空间                            │
│     available_height = 400 - (10*2) = 380  │
│     available_width = 300 - (10*2) = 280   │
└────────────┬───────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────┐
│  2. 扫描子视图                              │
│     固定高度总和 = 0                        │
│     权重总和 = 0                            │
│                                             │
│     子视图1: height=50  → 固定高度 +50      │
│     子视图2: weight=1   → 权重 +1           │
│     子视图3: weight=2   → 权重 +2           │
└────────────┬───────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────┐
│  3. 计算权重空间                            │
│     剩余空间 = 380 - 50 = 330              │
│     总权重 = 1 + 2 = 3                     │
│     单位权重 = 330 / 3 = 110               │
└────────────┬───────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────┐
│  4. 分配位置和尺寸                          │
│                                             │
│  ┌────────────────────────────────────┐   │
│  │ 子视图1: y=10, h=50                │   │
│  └────────────────────────────────────┘   │
│  ┌────────────────────────────────────┐   │
│  │ 子视图2: y=60, h=110 (1*110)       │   │
│  │                                    │   │
│  └────────────────────────────────────┘   │
│  ┌────────────────────────────────────┐   │
│  │ 子视图3: y=170, h=220 (2*110)      │   │
│  │                                    │   │
│  │                                    │   │
│  └────────────────────────────────────┘   │
└────────────┬───────────────────────────────┘
             │
             ↓
┌────────────────────────────────────────────┐
│  5. 通知子视图                              │
│     child:change_from_parent()             │
│     • 子视图更新自己的布局                  │
│     • 递归处理子视图的子视图                │
└────────────────────────────────────────────┘
```

## 7. 事件系统架构

```
                 ┌──────────────────┐
                 │  events_system   │
                 └────────┬─────────┘
                          │
          ┌───────────────┼───────────────┐
          │               │               │
          ↓               ↓               ↓
    ┌──────────┐   ┌──────────┐   ┌──────────┐
    │ Event 1  │   │ Event 2  │   │ Event N  │
    └────┬─────┘   └────┬─────┘   └────┬─────┘
         │              │              │
    subscribers    subscribers    subscribers
         │              │              │
    ┌────┴────┐    ┌────┴────┐    ┌────┴────┐
    │         │    │         │    │         │
    ↓         ↓    ↓         ↓    ↓         ↓
  ┌───┐    ┌───┐ ┌───┐    ┌───┐ ┌───┐    ┌───┐
  │S1 │    │S2 │ │S3 │    │S4 │ │S5 │    │S6 │
  └───┘    └───┘ └───┘    └───┘ └───┘    └───┘
   │        │     │        │     │        │
   ↓        ↓     ↓        ↓     ↓        ↓
callback callback callback callback ...

订阅流程:
─────────
1. Component → subscribe("event_name", callback, once, self)
2. events_system 创建 subscriber 记录
3. 分配唯一 sub_id
4. 存储到 subscribers[event_name][sub_id]
5. 返回 sub_id (用于取消订阅)

发布流程:
─────────
1. Publisher → publish("event_name", ...args)
2. events_system 查找 subscribers[event_name]
3. 遍历所有订阅者
4. 调用 callback(...args)
5. 如果是 once 订阅，自动取消订阅
```

## 8. 输入处理状态机

```
        ┌─────────────────────────┐
        │   IDLE (空闲状态)        │
        │   hover_view = nil       │
        │   pressed_views = {}     │
        └──────────┬────────────────┘
                   │
         鼠标移动  │
                   ↓
        ┌─────────────────────────┐
        │   HOVER (悬停状态)       │
        │   hover_view = view_x    │
   ┌───→│   isHover = true         │
   │    └──────────┬────────────────┘
   │               │
   │     鼠标按下  │
   │               ↓
   │    ┌─────────────────────────┐
   │    │   PRESSED (按下状态)     │
   │    │   pressed_views[id] = x  │
   └────┤   isPressed = true       │
        └──────────┬────────────────┘
                   │
         拖动      │
                   ↓
        ┌─────────────────────────┐
        │   DRAGGING (拖动状态)    │
   ┌───→│   isDragging = true      │
   │    │   (持续触发 mousemoved)  │
   │    └──────────┬────────────────┘
   │               │
   └───────────────┘
                   │
         鼠标释放  │
                   ↓
        ┌─────────────────────────┐
        │   RELEASED (释放状态)    │
        │   触发 on_click (可选)   │
        │   清空 pressed_views[id] │
        └──────────┬────────────────┘
                   │
                   ↓
         返回 IDLE 或 HOVER
```

## 9. 跨平台输入映射

```
┌──────────────────────────────────────────────────┐
│              Windows / Linux                     │
│                                                  │
│  love.mousemoved(x, y, dx, dy, istouch)         │
│  love.mousepressed(x, y, button, istouch)       │
│  love.mousereleased(x, y, button, istouch)      │
│  love.wheelmoved(x, y)                          │
└─────────────────────┬────────────────────────────┘
                      │
                      ↓
        ┌─────────────────────────┐
        │   统一接口转换           │
        │   (GUI Manager)         │
        └─────────────┬───────────┘
                      ↓
        ┌─────────────────────────┐
        │ gui:mousemoved(id,x,y)  │
        │ gui:mousepressed(id,x,y)│
        │ gui:mousereleased(...)  │
        │ gui:wheelmoved(id,x,y)  │
        └─────────────┬───────────┘
                      ↑
┌─────────────────────┴────────────────────────────┐
│                 Android                          │
│                                                  │
│  love.touchpressed(id, x, y, dx, dy, pressure)  │
│  love.touchmoved(id, x, y, dx, dy, pressure)    │
│  love.touchreleased(id, x, y, dx, dy, pressure) │
│                                                  │
│  触摸 ID 转换: userdata → numeric (1-10)         │
└──────────────────────────────────────────────────┘

统一后的接口:
──────────────
• id: 输入设备标识 (鼠标按钮/触摸点)
• x, y: 屏幕坐标
• dx, dy: 增量 (可选)
• istouch: 是否触摸输入
• pressure: 压力值 (可选)
```

## 10. 内存管理模型

```
┌──────────────────────────────────────────┐
│  GUI Manager                             │
│                                          │
│  views = setmetatable({}, {__mode='kv'})│ ← 弱引用表
│  ┌────────────────────────────────────┐ │
│  │  [id1] → view1 (weak)              │ │
│  │  [id2] → view2 (weak)              │ │
│  │  [id3] → view3 (weak)              │ │
│  └────────────────────────────────────┘ │
│                                          │
│  tree_views = { [1]={}, [2]={}, ... }   │ ← 强引用
│  ┌────────────────────────────────────┐ │
│  │  Layer 1: [view1, view2]           │ │
│  │  Layer 2: [view3]                  │ │
│  └────────────────────────────────────┘ │
└──────────────────────────────────────────┘

视图引用关系:
────────────

 Parent View (强引用)
      │
      ├─> children[] (强引用数组)
      │      ├─> Child1
      │      ├─> Child2
      │      └─> Child3
      │           │
      └───────────┴─> parent (强引用)

清理流程:
────────

1. 从 tree_views 移除 → 失去强引用
2. 从 views 弱引用表中自动移除
3. 如果没有其他强引用 → Lua GC 回收
4. 子视图的 parent 引用清空 → 级联回收

优点:
─────
• 自动防止内存泄漏
• 无需手动管理引用计数
• 循环引用自动解决
```
